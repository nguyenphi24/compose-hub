# Compose Hub

> Centralized Docker Compose Management Platform

Compose Hub is an open-source platform for managing, deploying, and monitoring Docker Compose applications across multiple servers from a single, intuitive dashboard.

## ✨ Features

- 🚀 Deploy Docker Compose projects with one click
- 🖥️ Manage multiple servers from a single dashboard
- 📦 Version-controlled Compose deployments
- 📄 View real-time container logs
- 🔄 Restart, recreate, or update services
- 🌱 Environment variable management
- 📊 Monitor container status and health
- 🔒 Secure remote deployment over SSH
- 👥 Multi-user and role-based access (planned)
- 🔌 Extensible plugin architecture (planned)

## 🚀 Getting Started

### Prerequisites

- Docker
- Docker Compose
- Linux Server (Ubuntu, Debian, Rocky, etc.)

### Installation

```bash
git clone https://github.com/compose-hub/compose-hub.git

cd compose-hub

docker compose up -d
```

Then open:

```
http://localhost:8080
```

## Why Compose Hub?

Docker Compose is simple, lightweight, and widely adopted, but managing dozens of Compose projects across multiple servers quickly becomes difficult.

Compose Hub provides a centralized experience similar to a lightweight PaaS while preserving the flexibility and simplicity of Docker Compose.
